## 🚀 DÉMARRAGE RAPIDE

### 1. Clone & Build

```bash
git clone https://github.com/jodwilliosafaridesir-design/safari.git
cd safari
./gradlew build
```

### 2. Install sur Tablette

```bash
./gradlew installDebug
```

### 3. Lancer l'App

- SAFARI PRO démarre directement
- Interface JARVIS s'affiche
- Prêt à utiliser!
